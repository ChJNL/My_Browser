# 검증 기록과 기기 확인 절차

## 현재 검증 결과

2026-11-22 기준으로 다음 사항을 확인했습니다.

- Gradle 8.14.3에서 Wrapper 생성이 성공했습니다.
- Wrapper JAR의 SHA-256은 Gradle 공식 값 `7d3a4ac4de1c32b59bc6a4eb8ecb8e612ccd0cf1ae1e99f66902da64df296172`과 일치했습니다.
- `NavigationInputTest`의 8개 테스트를 로컬 Kotlin 컴파일러와 JUnit 4.13.2로 직접 실행했고 모두 통과했습니다. Android Gradle 테스트 작업으로 실행한 결과는 아닙니다.
- SDK 36의 `aapt2`로 XML 리소스를 컴파일하고 링크했습니다. 직접 링크 검사에서는 Gradle이 보통 주입하는 패키지 이름을 임시 매니페스트에 추가했습니다. GeckoView를 포함한 최종 매니페스트 병합 검사는 아직 수행하지 못했습니다.
- GitHub Actions 워크플로 2개를 중복 키를 거부하는 YAML 파서로 읽었고, 셸 명령 블록 9개와 `gradlew`의 Bash 문법 검사가 통과했습니다. GitHub 서버에서 워크플로를 실행한 결과는 아닙니다.
- 서명 환경 변수가 없는 상태에서 `:app:requireReleaseSigning`을 실행했고, 의도한 오류로 중단되는 것을 확인했습니다. 실제 키를 사용한 서명 검증은 아직 수행하지 못했습니다.
- Gradle이 프로젝트 설정을 읽고 `:app:checkDebugAarMetadata`까지 실행한 뒤, GeckoView 캐시 부재로 중단됐습니다.
- 외부 Maven 서버 접속이 제한되어 전체 컴파일·정적 검사·APK 생성을 완료하지 못했습니다.
- `adb`는 `.android` 디렉터리 생성 권한 오류로 실행하지 못했습니다. 기기 실행 결과는 아직 없습니다.
- GitHub Actions와 Releases는 아직 실행하지 않았습니다.

## 자동 검사

네트워크에 접속할 수 있는 개발 환경에서는 다음 명령을 사용합니다.

```powershell
./gradlew.bat testDebugUnitTest lintDebug assembleDebug
```

GitHub의 `APK 빌드 및 검사` 워크플로도 같은 검사를 실행합니다.

## 기기 확인 항목

각 항목의 실제 결과를 기록하기 전에는 통과한 것으로 취급하지 않습니다.

| 항목 | 기대 결과 | 현재 상태 |
|---|---|---|
| 첫 실행 | 다크 테마, 주소창, 시작 안내가 표시됩니다. | 미검증 |
| HTTPS 주소 입력 | 다른 브라우저가 열리지 않고 앱 내부에 표시됩니다. | 미검증 |
| 스킴 없는 도메인 | HTTPS 주소로 보정됩니다. | 로직 테스트 통과, 기기 미검증 |
| 명시적 HTTP 주소 | HTTP 웹페이지가 표시됩니다. | 미검증 |
| 한글·공백 검색어 | DuckDuckGo 검색 결과로 이동합니다. | 로직 테스트 통과, 기기 미검증 |
| JavaScript 페이지 | 페이지 내 스크립트가 동작합니다. | 미검증 |
| 페이지 이동 | 제목, 최종 주소, 로딩 진행률이 갱신됩니다. | 미검증 |
| 뒤로·앞으로·새로고침 | 세션 상태에 맞게 이동하고 버튼이 활성화됩니다. | 미검증 |
| 새 창 링크 | 새 탭을 만들지 않고 현재 화면에서 엽니다. | 미검증 |
| 네트워크 단절·인증서 오류 | 오류 안내와 재시도 버튼이 표시됩니다. 인증서 오류를 우회하지 않습니다. | 미검증 |
| 지원하지 않는 스킴 | 실행을 거부하고 안내합니다. | 로직 테스트 통과, 기기 미검증 |
| 키보드·가로 회전 | 주소창과 하단 버튼이 조작 가능하고 페이지가 유지됩니다. | 미검증 |
| 백그라운드 복귀 | 열려 있는 세션을 다시 표시합니다. | 미검증 |
| 시스템의 프로세스 종료 후 복원 | 현재 주소를 다시 엽니다. 세션의 이전 이동 기록은 복원하지 않습니다. | 미검증 |
| 라이선스·엔진 빌드 정보 | 각 엔진 내장 정보 화면이 표시됩니다. | 미검증 |
| 서명한 APK 설치 | Android 8.0 이상 기기에 설치됩니다. | 미검증 |
| APK 업데이트 | 같은 키로 서명하고 versionCode가 증가한 APK를 기존 앱 위에 설치할 수 있습니다. | 미검증 |

최소 지원 버전인 Android 8.0과 SDK 36에 해당하는 Android 16에서 확인하고, 작은 화면·큰 글자 설정에서도 확인합니다.
