# 🌐 MyBrowser
### GeckoView 기반 독립형 Android 브라우저

**MyBrowser**는 Mozilla의 GeckoView 엔진을 활용하여 개발하는 독립형 Android 브라우저 프로젝트입니다.

기존 상용 브라우저의 복잡한 기능과 인터페이스에서 벗어나, 필요한 기능만 갖춘 가볍고 직관적인 개인 브라우저를 만드는 것을 목표로 합니다.

---

## 1. 프로젝트 소개

### 프로젝트 목적

기존 브라우저를 단순히 사용하는 것에서 벗어나 브라우저의 작동 구조와 렌더링 기술을 직접 경험하고, 나만의 독립적인 Android 브라우저를 개발하는 것이 목적입니다.

Mozilla GeckoView를 활용하여 별도의 브라우저 앱을 제작하고, URL 입력부터 웹페이지 렌더링까지 앱 내부에서 처리하도록 구현합니다.

### 개발 방향

- 기존 Chrome 및 Chromium 기반이 아닌 Gecko 엔진 사용
- Android 네이티브 기반 독립형 앱 개발
- 불필요한 기능을 최소화한 심플한 UI
- 안정적인 웹사이트 접속 환경 구현
- 단계적인 기능 확장 및 유지보수 고려

## 2. 기술 스택

| 구분 | 기술 |
|---|---|
| 플랫폼 | Android |
| 개발 언어 | Kotlin |
| 개발 환경 | Android Studio |
| 렌더링 엔진 | Mozilla GeckoView |
| UI | XML Layout |
| 빌드 시스템 | Gradle (Kotlin DSL) |
| 버전 관리 | Git / GitHub |

### 핵심 기술

**GeckoView**

Mozilla에서 제공하는 Android용 브라우저 엔진입니다.

HTML, CSS, JavaScript를 처리하고 웹페이지를 렌더링하는 역할을 담당합니다.

공식 저장소: https://github.com/mozilla/geckoview

## 3. 주요 기능

### 3.1 기본 브라우저 기능

- URL 주소 입력 및 웹사이트 접속
- 검색어 입력 및 검색 엔진 연동
- HTTP / HTTPS 페이지 접속
- 뒤로 가기 및 앞으로 가기
- 페이지 새로고침
- 웹페이지 제목 표시
- 페이지 로딩 상태 표시

### 3.2 사용자 인터페이스

- 미니멀한 브라우저 디자인
- 다크 모드 지원
- 직관적인 주소 입력창
- 하단 브라우저 내비게이션
- 로딩 인디케이터
- 인터넷 연결 오류 화면
- 다양한 스마트폰 화면 크기 대응

### 3.3 향후 추가 기능

- 다중 탭 시스템
- 즐겨찾기 관리
- 방문 기록 관리
- 다운로드 관리
- 검색 엔진 변경
- 브라우저 설정 화면
- 개인정보 및 사이트 데이터 관리

---

## 4. UI / UX 디자인 방향

MyBrowser는 복잡한 인터페이스보다 사용 편의성과 가독성을 우선합니다.

**디자인 원칙**

1. 미니멀하고 직관적인 인터페이스
2. 불필요한 메뉴와 장식 최소화
3. 모바일 환경에 최적화된 조작 방식
4. 일관성 있는 아이콘과 디자인
5. 다크 모드를 기본 테마로 제공

### 기본 화면 구성

- 상단: URL 주소 입력창 및 메뉴
- 중앙: 웹페이지 표시 영역
- 하단: 뒤로 가기, 앞으로 가기, 새로고침, 탭 버튼
